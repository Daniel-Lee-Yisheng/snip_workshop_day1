# Snip Frontend

The Angular 19 client shortens HTTP and HTTPS URLs through the Snip API at
`http://localhost:3000`.

Start the backend from the `backend` checkout with `bun start`, then run this
client with:

```bash
npm start
```

Open `http://localhost:4200`. To create a production build, run `npm run build`;
the output is written to `dist/snip-frontend/browser`.
